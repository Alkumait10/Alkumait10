## 💻 About Me

I’m a self-taught **.NET Backend Developer** with a solid understanding of backend fundamentals.  
I specialize in building RESTful APIs from scratch using **C#, ASP.NET Core, SQL Server, and Entity Framework Core**.

My technical focus goes beyond basic CRUD operations.  
I design systems using **Clean Architecture** and implement advanced patterns like **CQRS**.  
I also utilize **AutoMapper, FluentValidation**, and write **Unit & Integration tests** to ensure code reliability and maintainability.  
Currently, I am expanding my DevOps skills by learning **Docker** to containerize and deploy applications.

I strongly believe in:
- Writing clean and readable code.
- Applying **SOLID** principles.
- Continuous learning and improvement.

### 🚀 Future Vision
My core backend skills are now ready for the job market, and my next milestone is to become a **Full Stack Developer**.  
I am currently transitioning into Frontend development — starting with HTML and CSS, and moving towards JavaScript and **React** — to seamlessly integrate powerful .NET backends with modern, dynamic user interfaces.
